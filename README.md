🎯 Face Recognition App with Voice Input and GUI Capture
This project is a Python-based face recognition system that uses a webcam to recognize faces, register new users, and confirm identities through voice input.

🔍 Features
✅ Real-time face recognition using your webcam

🧠 Remembers faces using a JSON-based encoding system

🎤 Voice input for user name confirmation via microphone

🖼️ GUI interface to take a face picture using Tkinter

🔁 Automatically updates and saves new face data

📁 Stores face images locally for easy management
